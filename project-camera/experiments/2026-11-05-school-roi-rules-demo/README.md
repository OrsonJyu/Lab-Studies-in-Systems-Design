# 2026-11-05 · school 检测区域与环境变化规则的替代场景演示

日期：2026-11-05（香港）15:44–15:50。代码为分支 `code/detection-roi-rules`（提交 `72968bb`）：只看网页上画出的检测区域；整幅画面 ≥30% 同时变化视为环境变化；变化块按大小过滤；运动要持续 0.5 秒。场景用白色收纳盒代替饲养箱、绿色玩具蜥蜴代替守宫，由用户在现场操作。

场景由我按录像内容和日志判断，用户只告知"已完成"，没有逐项报时间；录像里有人，未放入仓库（片段在用户 Mac 的 `recordings/`）。

## 解读

- **检测区域有效**：设区域前，背景里的人就能触发录制；设区域后约 2 分钟的背景活动没有触发。
- **环境变化能识别，但余量很小**：这次是 31.4%，只比 30% 高一点；稍弱的光线变化会被当成运动。需要知道 15:48:55 做了什么（开关灯还是手电筒），再决定阈值是否降到 20% 左右。
- **"手太大就不算"基本没起作用**：帧差只在物体的边缘产生变化，手的变化块很少超过区域的 35%。用变化块的面积判断大小不可靠；下一步改用背景差（整只手都是前景）或变化块的外框大小，会更可靠。另外，手推动玩具时玩具确实在动，这种情况录下来不算错。
- 参数是按玩具场景设的初始值，不代表守宫场景。

## 限制

- 各场景的时间和动作是根据录像推断的，不是用户逐项报的。
- 环境变化那一次的原因没有画面可看。
- 每帧的判断只记录了每 10 秒的统计，不能逐帧还原；如需逐帧对比，应保存一段原始录像离线回放。
- 只做了一轮，没有重复。
