# school · 网络迁移、SSH 与 IINA 预览

日期：2026-10-30（香港）。目标：在学校重新建立 Mac 与 ROCK 的管理连接，以及可用的摄像头预览路径。最终接线与配置边界见 [school 环境](../../environments/school/README.md)；可复现步骤见[指南](../../../docs/guides/SCHOOL_NETWORK_AND_PREVIEW_GUIDE.md)。

## 证据形式

本记录整理本次对话中的用户截图、用户确认及当时执行的只读网络/媒体检查。原始接线照片和终端截图留在本地，未上传原图；不附完整对话、工具日志、真实地址、凭据或机器路径。结构化观察是人工整理，**不是重新执行实验的原始日志**。

本目录只有说明与去私有值的 JSON，没有新视频文件。`manifest.json` 核对这些整理文件的字节，不证明原始截图已归档或测试可独立重放。软件版本仅登记已观察到的项目，不从其他日期倒填 IINA 版本。

## 操作与观察顺序

1. **校园网络限制。** Mac 已连接学校 Wi-Fi，macOS 弹窗拒绝共享受 802.1X 保护的连接。未以此认定学校存在全局客户端隔离。USB-C 供电线未建立本次管理网络。
2. **有线管理。** 复用现有网线连接 Mac 和 ROCK；找到板卡本地 IPv6，核对已知主机密钥并成功 SSH。Mac 侧 Wi-Fi 邻居表和旧 DHCP 租约不能作为板卡地址证明。后来使用静态有线配置也曾登录成功。
3. **另一台电脑热点。** 板卡终端显示无线已连接并取得 IPv4，Mac 侧核对无线 SSH 主机身份。给板卡有线接口临时加摄像头网段地址，首次端口超时；随后截图显示临时 IPv4 已消失，ping 选用了 Wi-Fi 源地址，而相机邻居记录可达。推断 NetworkManager 的 DHCP 重试/重新激活可能清理了临时地址，未采集足以证明唯一原因的服务日志。
4. **保存有线配置。** 创建并启用 `school-camera`，静态 IPv4、不设置有线默认路由、手动启用。用户截图确认路由从有线接口到相机，80/554/8899 TCP 端口均连通。端口连通不等于完成 ONVIF 协议读取或视频预览。
5. **电脑热点预览。** FFplay 进程和视频探测正常；首次两秒解码检查返回非零，随后显式选择视频流的三秒解码通过。用户仍报告“有窗口，但黑屏或画面不动”，因此该变体不记作可视预览成功。
6. **iPhone 热点与 IINA。** 有线管理保留期间让 ROCK 与 Mac 连接同一手机热点，另建本机 SSH 转发入口。先出现间歇 SSH 超时；后来用户明确回复“可以看到预览，但是网络太差了”。实际可视预览通过，质量只有定性反馈；无测速或延迟测量。兼容参数和重试是尝试，不建立 QoS/代理的因果结论。
7. **ROCK 自建热点。** 用户截图显示 AP 支持为 yes，已有 `rock-lab-ap`。在有线管理前提下复用 AP 配置，独立 shared IPv4 网段、WPA-PSK/RSN、手动启用；用户在无线 SSH 操作说明后回复“成功”。没有把它记成已通过持续视频或外网接入。
8. **最终全有线。** 用户拿到额外网线，选择各数据端接同一交换机。Mac 有线接口为 100 Mbps 全双工；相机 80/554/8899 均可达。Mac 直接探测得到 H.264、2560 × 1440、`r_frame_rate=20/1`；三秒视频解码命令退出码为 0，stderr 为空。使用独立本机有线 IINA 入口后，用户回复“成功”。

## 本次可确认的结论

- `school` 已有有限的管理、热点及预览证据，不再是从未测试的预留环境。
- 最终预览是**摄像头 → 交换机 → Mac**，不需要经 ROCK 取流或经手机转发。Mac 可另以校园 Wi-Fi 上网。
- 板卡固定有线 IPv4 在不同阶段出现过未启用/丢失；**末次检查时固定 IPv4/SSH 未恢复，IPv6 仅 ICMP 回应，SSH 未通过**。最后一次用户“成功”只确认 IINA 有线预览，不扩大成板卡管理恢复。
- 本次 saved NetworkManager 配置均为手动启用；保存配置不等于开机自动连接。旧连接仍保留，跨环境切换需显式选择。

## 限制与下一步

没有学校新录像、录制时长/帧数文件验证、预录制、SATA、长时间稳定性、自动恢复或时钟校准结论。三秒 decode 是短检查，20 fps 是流报告值，不是持续性能实测。最终接线后需恢复 ROCK 管理，验证板卡到相机和新录像，再做长期与故障测试。

用户完成现场接线、终端认证并观察画面；助手提供配置步骤、本机预览入口并执行部分检查。不推定其他组员贡献、课程验收或平台提交。
