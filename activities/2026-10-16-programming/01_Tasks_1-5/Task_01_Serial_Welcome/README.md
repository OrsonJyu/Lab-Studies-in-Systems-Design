# Task 1: Serial Welcome

Open `Task01_Serial_Welcome/Task01_Serial_Welcome.ino` in Arduino IDE. Keep SerialInput.h alongside the sketch where included.

Board: LuatOS ESP32C3 / ESP32C3 Dev Module. Serial Monitor: 115200 baud, Newline (or Both NL & CR). Use the supplied IO_Control_20260330b library and its dependencies.

## Test and evidence

Reset the board and capture Serial Monitor showing several lines. First handler output is due at 1500ms, then every 100ms. Expected format: `Welcome, current time since start = 1500`. Actual timestamps may be a few milliseconds late due to scheduling. Required evidence: one real Serial Monitor screenshot.
