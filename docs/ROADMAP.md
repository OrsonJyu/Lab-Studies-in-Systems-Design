# 后续工作 / Roadmap

这是从既有讨论整理的**建议验证顺序**，不新增课程 deadline 或人员承诺。

| 阶段 | 要解决的问题 | 应留下的产出 |
| --- | --- | --- |
| 1 设备与接口 | 摄像头确切型号、视频流、运动事件接口、PoE、ROCK 4C+ 系统与硬盘连接方式 | 设备/接口清单，连接图，读流与回放日志 |
| 2 最小录制 | 单路持续接收、分段与本地保存是否稳定 | 配置、源码、版本、连续运行日志、可播放录像 |
| 3 预录制 | 测试事件能否保留 T−n 到尾段；时间线是否对齐 | 事件时间、接收时间、片段实际边界、原始录像与结果 |
| 4 故障与保留 | 重叠事件、关键帧、延迟、断流、重启、磁盘满、过期删除 | 复现步骤、失败及恢复记录、保留策略 |
| 5 跨组集成 | 时间戳/ID/事件标签、事件协议、API 与责任分工 | 双方确认的接口草案和一条联合事件链 |
| 6 热阵列和分析 | 可见性、热阵列测量、位置/轨迹与候选行为如何核对 | 原始样本、人工核对、缺口/错误、性能限制 |
| 7 使用目标 | 学生能否找到证据、比较记录并形成观察问题 | 使用任务、观察与反馈，不把技术演示当学习成效证明 |
