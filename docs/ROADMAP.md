## 移动环境与下一项验证依赖

家庭环境为 `home`；[school](../project-camera/environments/school/README.md) 已有电脑热点、iPhone、ROCK AP 与最终有线变体。macOS 拒绝本次 802.1X 来源共享，不代表学校全局设备隔离已测清。通用 `hotspot` 仍预留；新的场地与设备组合各自验收，不改写 home 原实验。

日常按[共用有线指南](guides/SHARED_WIRED_NETWORK_GUIDE.md)检查，同一私有 JSON 只改变地点标签。下一阶段先确定运动/静止 n 秒与预录窗口，再用手验证事件片段、前段完整性和延迟；网站为后续可选。新学校现场复测、时钟、持续性/故障、SATA各自验收，不能以网络自启代替录制服务。
