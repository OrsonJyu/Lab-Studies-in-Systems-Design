## 项目与小组职责
课程项目围绕中小学豹纹守宫照护与学习系统。用户小组负责摄像头模组及相关热阵列数据采集、保存与调用。
## 用户提供的技术方向
首选：PoE IP Camera → Radxa Rock 5C 接收及图像处理 → SSD。
备选：UVC Camera → ESP32-P4 → SD 卡录制 → 远程取回并汇入后端。
热阵列候选为 MLX90640，需考虑数据保存、远程获取及与其他单元共享。
